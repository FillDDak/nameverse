# NAMEVERSE — 이름의 우주

> **당신의 이름은 이미 하나의 행성입니다.**

이름을 입력하면 NASA가 확인한 **실제 외계행성 6,306개** 중 하나와 연결해 줍니다.
같은 이름은 전 세계 어느 기기에서 입력해도 **완전히 같은 행성**이 됩니다.
실제 관측 데이터에 상상의 이야기와 상상도를 더했고, 서버나 API 키 없이 정적 파일만으로 동작합니다.

➡️ 링크: https://fillddak.github.io/nameverse/

## 실행

빌드가 필요 없습니다.

- **가장 간단하게:** `index.html`을 더블클릭해 브라우저로 엽니다.
- **로컬 서버 (권장, 링크 복사 등이 더 잘 동작):**
  ```bash
  python -m http.server 8000
  # 또는: npx serve .
  ```
  그런 다음 http://localhost:8000 에 접속합니다.
- **배포:** 폴더를 GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 그대로 올리면 됩니다.

## 기능

| | |
|---|---|
| 🔭 **실제 외계행성** | NASA Exoplanet Archive의 확인된 외계행성(논란 있는 행성 제외)에서 이름마다 하나를 고릅니다. 크기, 질량, 공전 주기, 궤도, 평형 온도, 지구 유사도(ESI), 모항성, 거리, 발견 연도·방법·시설, 실제 별자리까지 보여 주고, 추정값에는 (추정)을 붙입니다. |
| 🪐 **실시간 레이트레이싱 행성** | WebGL 프래그먼트 셰이더 하나로 지형(도메인 워핑 fBm), 바다의 반사광, 구름, 극지방 얼음, 밤 쪽 도시 불빛, 대기 산란, 가스 거인의 띠와 소용돌이 폭풍, 용암 균열의 발광, 고리(행성 그림자 포함), 위성, **일식(위성 그림자)**까지 그립니다. |
| 🌌 **실제 수치로 고르는 모습** | 반지름과 평형 온도로 가스 거인 · 얼음 거인 · 용암 · 사막 · 바다 · 빙하 등 10가지 모습 중 하나를 고릅니다. 가스 행성의 색은 온도로(차가운 토성형 ~ 검붉은 뜨거운 목성), 햇빛의 색은 모항성 온도로 정합니다. 고리와 위성은 관측된 적이 없어 상상으로 그립니다. |
| ⌨️ **입력하는 동안 떠오르는 행성** | 한 글자를 칠 때마다 지평선 너머의 행성이 실시간으로 바뀝니다. |
| 🚀 **워프 연출** | 3D 별밭이 초공간 도약처럼 늘어나며 좌표를 스캔합니다. |
| 📜 **관측 기록 + 상상 기록** | 관측 기록(발견 방법 설명, 환경, 그 행성에서 본 하늘)은 실제 데이터로 쓰고, 상상 기록(풍경, 생명, 현상, 속담, 태그, "이 행성에서 당신의 직업")은 따로 구분합니다. 조사(이/가, 은/는…)는 받침에 맞춰 자동으로 고릅니다. |
| 💎 **희귀도** | 평범 · 특별 · 희귀 · 전설 · 신화. 생명 가능 영역의 암석 행성, 가까운 이웃, 직접 촬영 등 실제로 드문 특징에 점수를 매겨 6,306개 중 순위를 냅니다. 이름이 행성을 균등하게 고르므로 "상위 X%"는 문자 그대로 사실입니다. |
| 🔭 **지표 탐사** | 행성을 누르면 그 지점이 바다인지, 산인지, 폭풍의 눈인지 알려 줍니다. 셰이더의 노이즈 함수를 JS로 그대로 옮겨 GPU 화면과 판정이 일치합니다. |
| 🎵 **행성의 노래** | 행성마다 선법(도리안·리디안·프리지안…), 조성, 템포, 화성 진행이 다른 앰비언트 음악을 Web Audio로 실시간 작곡합니다. 음악에 맞춰 대기가 숨을 쉽니다. |
| 💞 **행성 궁합** | 두 이름의 행성을 나란히 띄우고 궁합 점수를 냅니다 (순서를 바꿔도 같은 결과). 두 행성 사이의 실제 거리와 공전 주기 비율도 알려 줍니다. |
| 🖼️ **발견 증명서** | 1080×1350 공유용 엽서 PNG를 만듭니다. 모바일에서는 공유 시트로 바로 보냅니다. |
| 🔗 **공유 링크** | `#n=이름`, `#n=이름&m=상대` 형태라서 링크를 받은 사람도 같은 행성을 봅니다. |
| 🗂️ **은하 도감** | 이 기기에서 발견한 행성을 기록합니다 (localStorage). |
| ⚡ **적응형 해상도** | 프레임이 떨어지면 렌더링 해상도를 자동으로 조절합니다. |

**조작:** 드래그로 행성 회전 · 오른쪽 드래그(Shift+드래그)나 두 손가락 드래그로 시점 이동 · 휠이나 핀치로 확대/축소 · 더블클릭으로 시점 초기화 · 클릭으로 지표 탐사 · `M` 음악 켜기/끄기 · `/` 입력창 포커스 · `Esc` 닫기

## 구조

```
index.html          화면 뼈대
js/exoplanets.js    NASA 외계행성 목록 (tools/build-exoplanets.js가 생성)
css/style.css       스타일 (데스크톱 · 모바일 바텀시트)
js/seed.js          cyrb128 해시 + sfc32 PRNG, 기능별 독립 난수 스트림(fork)
js/genesis.js       이름 → 실제 행성 → 모습, 관측·상상 기록, 음악 파라미터, 궁합
js/planet-gl.js     WebGL 레이트레이싱 렌더러 + 클릭 판정(pick)
js/surface.js       셰이더 노이즈의 JS 이식 → 지표 판정과 지명 생성
js/music.js         Web Audio 생성 음악 (패드, 아르페지오, 베이스, FM 벨, 잔향, 딜레이)
js/starfield.js     시차 별밭, 별똥별, 워프
js/postcard.js      공유용 엽서 합성
js/app.js           화면 흐름, 라우팅, 상호작용
tests/genesis.test.js   생성기 검사: 결정성, 1만 개 이름 무결성, 조사, 희귀도 분포
tests/gallery.html      개발용: 여러 행성을 한 화면에 (?names=a,b,c&cols=4)
tools/build-exoplanets.js  NASA Exoplanet Archive에서 목록을 받아 js/exoplanets.js 생성 (IAU 별자리 경계로 별자리 판정)
```

## 테스트

```bash
node tests/genesis.test.js
```

## 데이터

- 출처: [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) — Planetary Systems Composite Parameters, 2026-09-25 기준
- 별자리: IAU 별자리 경계 (Roman 1987, CDS VI/42)
- 비어 있는 값은 질량-반지름 관계식(Chen & Kipping 2017)과 모항성 온도·반지름·궤도로 계산한 평형 온도(반사율 0.3 가정)로 채우고, 화면에 (추정)으로 표시합니다.

> ⚠️ 이름 → 행성 연결은 `js/exoplanets.js`의 행 순서에 달려 있습니다. `tools/build-exoplanets.js`를 다시 실행하면 목록이 바뀌어 이미 공유된 링크의 행성이 달라지니, 데이터 갱신이 꼭 필요할 때만 실행하세요.

> ⚠️ 행성의 결정성은 `js/genesis.js`의 생성 순서에 달려 있습니다. 이미 공유된 링크의 행성을 바꾸지 않으려면, 기존 난수 호출 순서를 건드리지 말고 새 기능에는 `root.fork('새이름')`으로 별도 스트림을 쓰세요.
