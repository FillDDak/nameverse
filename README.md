# NAMEVERSE — 이름의 우주

> **당신의 이름은 이미 하나의 행성입니다.**

이름을 입력하면 우주 어딘가에서 **그 이름으로만 존재하는 행성**을 찾아냅니다.
같은 이름은 전 세계 어느 기기에서 입력해도 **완전히 같은 행성**이 됩니다.
서버도, 데이터베이스도, API 키도 없이 이름 하나에서 모든 것을 결정론적으로 만들어 냅니다.

🌐 **바로 체험하기:** https://fillddak.github.io/nameverse/

## 실행

빌드가 필요 없습니다.

- **가장 간단하게:** `index.html`을 더블클릭해 브라우저로 엽니다.
- **로컬 서버 (권장, 링크 복사 등이 더 잘 동작):**
  ```bash
  python -m http.server 8000
  # 또는: npx serve .
  ```
  그런 다음 http://localhost:8000 에 접속합니다.
- **배포:** 폴더를 GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 그대로 올리면 됩니다.

## 기능

| | |
|---|---|
| 🪐 **실시간 레이트레이싱 행성** | WebGL 프래그먼트 셰이더 하나로 지형(도메인 워핑 fBm), 바다의 반사광, 구름, 극지방 얼음, 밤 쪽 도시 불빛, 대기 산란, 가스 거인의 띠와 소용돌이 폭풍, 용암 균열의 발광, 고리(행성 그림자 포함), 위성, **일식(위성 그림자)**까지 그립니다. |
| 🌌 **10가지 생물군계** | 푸른 대양, 에메랄드 정원, 붉은 사막, 보랏빛 이계, 산호빛 황혼, 줄무늬 가스 거인, 청록빛 얼음 거인, 용암 대장간, 흑요석 수정, 고요한 빙하 |
| ⌨️ **입력하는 동안 떠오르는 행성** | 한 글자를 칠 때마다 지평선 너머의 행성이 실시간으로 바뀝니다. |
| 🚀 **워프 연출** | 3D 별밭이 초공간 도약처럼 늘어나며 좌표를 스캔합니다. |
| 📜 **행성의 역사** | 발견 설화, 풍경, 하늘, 생명체, 기이한 현상, 속담, 성격 태그, 그리고 "이 행성에서 당신의 직업"까지. 조사(이/가, 은/는…)는 받침에 맞춰 자동으로 고릅니다. |
| 💎 **희귀도** | 평범 · 특별 · 희귀 · 전설 · 신화. 균등 분포라서 "상위 X%"는 문자 그대로 사실입니다. |
| 🔭 **지표 탐사** | 행성을 누르면 그 지점이 바다인지, 산인지, 폭풍의 눈인지 알려 줍니다. 셰이더의 노이즈 함수를 JS로 그대로 옮겨 GPU 화면과 판정이 일치합니다. |
| 🎵 **행성의 노래** | 행성마다 선법(도리안·리디안·프리지안…), 조성, 템포, 화성 진행이 다른 앰비언트 음악을 Web Audio로 실시간 작곡합니다. 음악에 맞춰 대기가 숨을 쉽니다. |
| 💞 **행성 궁합** | 두 이름의 행성을 나란히 띄우고 중력 궁합을 계산합니다 (순서를 바꿔도 같은 결과). |
| 🖼️ **발견 증명서** | 1080×1350 공유용 엽서 PNG를 만듭니다. 모바일에서는 공유 시트로 바로 보냅니다. |
| 🔗 **공유 링크** | `#n=이름`, `#n=이름&m=상대` 형태라서 링크를 받은 사람도 같은 행성을 봅니다. |
| 🗂️ **은하 도감** | 이 기기에서 발견한 행성을 기록합니다 (localStorage). |
| ⚡ **적응형 해상도** | 프레임이 떨어지면 렌더링 해상도를 자동으로 조절합니다. |

**조작:** 드래그로 회전 · 휠로 확대/축소 · 클릭으로 지표 탐사 · `M` 음악 켜기/끄기 · `/` 입력창 포커스 · `Esc` 닫기

## 구조

```
index.html          화면 뼈대
css/style.css       스타일 (데스크톱 · 모바일 바텀시트)
js/seed.js          cyrb128 해시 + sfc32 PRNG, 기능별 독립 난수 스트림(fork)
js/genesis.js       이름 → 행성의 모든 것 (생물군계, 수치, 이야기, 음악 파라미터, 궁합)
js/planet-gl.js     WebGL 레이트레이싱 렌더러 + 클릭 판정(pick)
js/surface.js       셰이더 노이즈의 JS 이식 → 지표 판정과 지명 생성
js/music.js         Web Audio 생성 음악 (패드, 아르페지오, 베이스, FM 벨, 잔향, 딜레이)
js/starfield.js     시차 별밭, 별똥별, 워프
js/postcard.js      공유용 엽서 합성
js/app.js           화면 흐름, 라우팅, 상호작용
tests/genesis.test.js   생성기 검사: 결정성, 1만 개 이름 무결성, 조사, 희귀도 분포
tests/gallery.html      개발용: 여러 행성을 한 화면에 (?names=a,b,c&cols=4)
```

## 테스트

```bash
node tests/genesis.test.js
```

> ⚠️ 행성의 결정성은 `js/genesis.js`의 생성 순서에 달려 있습니다. 이미 공유된 링크의 행성을 바꾸지 않으려면, 기존 난수 호출 순서를 건드리지 말고 새 기능에는 `root.fork('새이름')`으로 별도 스트림을 쓰세요.
